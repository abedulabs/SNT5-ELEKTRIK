## Terbitkan menggunakan GitHub Pages
1. Cipta repository baharu atau buka repository sedia ada.
2. Muat naik `index.html` ke root repository (bukan dalam subfolder).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
5. Buka URL GitHub Pages yang dipaparkan.
